# AluraBooks - Responsividade

Este repositório contém o projeto **AluraBooks**, desenvolvido durante os cursos de Front-end da Alura. O foco principal deste projeto foi o aprendizado de técnicas de **Design Responsivo**, garantindo que a interface da livraria online seja acessível e elegante em qualquer tamanho de tela.

---

## Tecnologias Utilizadas

O projeto foi construído utilizando as melhores práticas de desenvolvimento web:

* **HTML5**: Estruturação semântica.
* **CSS3**: Estilização avançada.
* **Flexbox & CSS Grid**: Para criação de layouts complexos e flexíveis.
* **Mobile-First**: Metodologia de desenvolvimento priorizando dispositivos móveis.
* **Swiper.js**: Biblioteca externa para a criação de carrosséis (sliders) interativos.
